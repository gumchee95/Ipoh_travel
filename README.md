# Ipoh Travel Route Explorer / 怡保旅游路线资料库

A static, civic, bilingual Ipoh route database. It helps travellers pick one place and understand the next connected places by map distance, manual route links, time slot, category and tags.

This is not an official tourism site, not a blog, not a wiki, and not a commercial ranking system.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- Leaflet CDN for the map
- CSV as the source data
- Generated JSON for browser loading
- No backend
- No login
- No React, Vue or Next

## Data Model

CSV files live in `data/csv/`.

JSON files live in `data/json/` and are generated by:

```bash
npm run build:data
```

Validate before building:

```bash
npm run validate:data
```

The first seeded database includes:

- 114 Ipoh-area places
- 20 bus stop references
- 12 manual point-to-point route links
- sponsor disclosure data that does not affect ranking

## Browser Data Source

The website loads `data/csv/*.csv` directly in the browser.

Generated JSON is kept as a deploy/debug fallback, but CSV is the primary runtime source.

## Excel Encoding Note

CSV files are written as UTF-8 with BOM so Windows Excel can detect Chinese text correctly when opening by double-click.

If Excel still shows garbled text, import the file through Excel's data import flow and choose UTF-8.

## Local Preview

Use a local server instead of opening `index.html` directly when possible, because browsers often block `file://` JSON loading.

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deployment

This project can be deployed to GitHub Pages or Netlify as a static site.

Build data first:

```bash
npm run prepare
```

Then deploy the repository root.

## Important Rules

- CSV is the editable source of truth.
- JSON is generated output.
- Bus stop locations marked `map_inferred` or `needs_verification` are not official GPS claims.
- BAS.MY / Pink Bus references must be verified before travellers rely on them.
- Sponsor data is disclosure-only and never changes recommendation scores.
- Contributions are manually reviewed before entering CSV.
